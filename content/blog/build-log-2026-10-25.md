Strata is meant to sit between an AI agent and the money it spends: check the agent was authorised, apply the limits, score the risk and keep a record nobody can quietly edit. None of that works without a payment core that never charges twice and never loses track of money. So the core comes first.

## Where things stand

| Phase | Part | State |
| --- | --- | --- |
| P1 | Payment core and ledger | About 70% |
| P2 | Mandate verification | Not started |
| P3 | Policy engine | Not started |
| P4 | Risk scoring | Not started |
| P5 | Tamper-evident audit | Not started |
| P6 | Attack harness and evaluation | Not started |
| P7 | Operator console | Not started |

## What's built

- **Idempotency done properly.** The idempotency key and the payment it creates commit in one transaction. The request hash is scoped to the caller, method, path and canonical body.
- **A double-entry ledger, append-only.** Money conservation is checked by a property test over 10,000 randomised create, settle, fail and refund operations: every payment's entries sum to zero, and so do all balances.
- **Settlement recovery.** A rail call that doesn't answer is recorded as unknown, never as failed, and resolved by asking the rail.
- **Deterministic rail references**, with a database uniqueness constraint as the guarantee.
- **A shared rail contract test suite.** The internal ledger rail and a persisted fake payment provider both pass it.

## What's measured

These are benchmarks on a development machine with in-process containers, not production figures:

- 100 concurrent requests with the same idempotency key produce exactly one payment, one posting and 100 identical responses. Verified on PostgreSQL alone, with the Redis lock, and with Redis down.
- The rail call adds roughly 0.3 ms at p50 with the fake provider and 0.8 ms with the internal ledger rail.

## What's next

Finish P1, then mandate verification and the policy engine. That's when there will be something to show: an agent attempting a payment and being refused because its mandate didn't allow it.
